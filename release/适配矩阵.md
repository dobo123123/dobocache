## 三类等级的含义

- **客户端确认**：真实客户端自己认过这条接入。老三家（Loomy / opencode / Claude Code）自 v0.5.3 起在 Windows 11 真机端到端验证；Codex CLI 在 v0.9.1 用 `codex mcp list` 复确认（见下）。
- **写入+回滚复算**：在本机真实文件系统上完整跑过写入、语法校验、条目校验与回滚还原，但**没有**对应客户端在这台机器上跑起来确认。这类在 `setup` 里参与自动接入，风险已被工程验证兜住。
- **仅指路（不写盘）**：配置格式无法安全代写（如 Crush 的 crushrc 是可执行风格），只输出手填指引，永不自动写。
